# Ingeniería IOCA — Sitio Web

## Cómo correr en local

1. Tener instalado Node.js (https://nodejs.org)
2. Abrir una terminal en esta carpeta
3. Correr:

```
npm install
npm start
```

El sitio abre automáticamente en http://localhost:3000

## Archivos principales

- `src/App.js` — todo el código del sitio
- `public/logo.gif` — logo de IOCA (reemplazar con el definitivo)

## Para subir a producción

```
npm run build
```

Subir la carpeta `build/` a Vercel, Netlify o cualquier hosting estático.
